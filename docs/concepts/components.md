# Graviton components

A Graviton component is a reusable piece of infrastructure that can be used
across multiple stacks. Components are defined in the
[components](https://github.com/orbitcloud/graviton-oss/tree/main/components/orbitcloud_graviton)
directory of the Graviton repository.

## Example components

The following are examples of components that can be used in Graviton:

| Component | Description |
| --------- | ----------- |
| [az_acr](https://) | Azure Container Registry |
| [az_monitor](https://) | Log Analytics workspaces, Application Insights & Diagnistic Settings  |
| [az_network](https://) | Virtual Networks, Subnets, Network Security Groups & Public IPs |
